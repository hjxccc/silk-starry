# 模板：Monorepo 根 CLAUDE.md 骨架

> 用于多子模块仓库的**根**文件。根只放跨仓共享规范 + 导航，子模块细节放各自 CLAUDE.md。

```markdown
# CLAUDE.md

## 项目概述
<一句话：这是一个编排 N 个子模块的 monorepo，各子模块用途一句话>

## 子模块导航（改哪个看哪个）
| 子模块 | 用途 | 看哪个文档 |
|---|---|---|
| <frontend> | <前端> | `<frontend>/CLAUDE.md` |
| <backend>  | <后端> | `<backend>/CLAUDE.md` |
| ...        | ...    | ... |

## 跨仓共享约定
- commit 格式：<约定>
- 分支协作：<开发分支 ↔ 主分支；推送前 pull>
- 共享规范（如建表/迁移）：<指向单一来源，避免各子仓各写一份漂移>

## 全局禁区
- 根目录禁止临时文件/调试脚本（放 <指定 scratch 目录>）。
- 不要改各子模块已发布的迁移文件。

## 工作方式
- 跨多个子模块的改动先列计划。改某个子模块前，先读它自己的 CLAUDE.md。
```

要点：
- 根文件**不要**复制子模块的细节，只做导航 + 真正跨仓的规范。
- 子模块 CLAUDE.md 按需懒加载，所以把模块特定规则留在子模块里最省 context。
- 已有 AGENTS.md（如 trellis 托管）时，根 CLAUDE.md 顶部 `@AGENTS.md` import，别复制。
